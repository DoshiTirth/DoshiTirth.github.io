Lakelands Community Care
Analytics Hub

A 3-page interactive Power BI dashboard built to visualize service delivery, program outcomes, staff operations, and budget performance for a Simcoe County community care organization.

Context Technical Interview — Empower Simcoe
Role Power Applications & AI Lead
Pages 3 — Program Overview · Service Delivery · Operations
Data Model Star Schema · 10 Tables · 13 DAX Measures
Live Interactive Dashboard

Use the slicers to filter by Region and Year. Navigate between pages using the tabs at the bottom. Requires a Power BI account to interact.  ·  Open in Power BI ↗

What the Dashboard Covers

🗺️
Page 1 — Program Overview
3D map visual (ArcGIS) showing client distribution across Simcoe County. KPI cards for active clients, service hours, services delivered, and avg outcome score. Bar chart by region + monthly trend line.
📊
Page 2 — Service Delivery Deep Dive
Donut chart for services by program, stacked bar for service types, outcome score trend by program, and a program vs service type matrix with conditional formatting.
⚙️
Page 3 — Operations & Resources
Budget allocated vs spent by program, scatter chart for staff hours vs training by shift type, incident analysis by severity, and a gauge for budget utilization.
🔗
Star Schema Data Model
10-table star schema with 5 fact tables (Service Delivery, Budget, Incidents, Staff Activity, Client Assessments) and 5 dimension tables. 13 custom DAX measures.
🎛️
Interactive Slicers
Year tile slicer (2022–2026) and Region dropdown filter that cross-filter all visuals simultaneously across every page of the report.
🎨
Custom Dark Theme
Consistent dark navy design system with teal accents throughout all 3 pages. Custom color palette, card backgrounds, and typography matching a professional BI standard.
